# Feed inventory and logistics (logistics)

## Cover
Feed cover is measured in hours of consumption at the current ration. Below 72
hours the site is exposed to a single missed delivery. Below 36 hours rationing
becomes unavoidable.

## Silo discipline
Each silo has an inlet that can trip. A tripped inlet looks like a slow decline
in inventory rather than an alarm, so it is easy to miss until cover is short.

## Convoy
Rerouting a convoy commits third-party haulage and is a human decision. Moving a
load between silos on site is not.

## Ration changes
Ration changes propagate to rumination within a day and to yield within three.
Any change should be recorded with the reason, because the effect arrives later
than the cause.
